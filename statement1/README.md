# Statement 1-Golang calculator

Program takes two float64 numbers and an operand and outputs result based on the operand  
I've used the table driven testing template for the test file

## Prerequisites
 - Go installed  
 Check using: go version

## How to run
1. Navigate to folder  
 cd statement1


2. Run program  
 go run main.go

3. Run tests  
 go test

## Sample input
------Cynthia's Calculator------
Enter first number: 1
Enter second number: 5
Enter the choice of operation (+,-,*,/): +
Result: 6
